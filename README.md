# 🎥 Real-Time Object Detection App (YOLO + Streamlit)

This project is a real-time object detection web app built using **Streamlit**, **YOLOv8 (Ultralytics)**, and **WebRTC**.  
It can detect, count, and alert when specific objects appear in a live video stream.

---

## 🚀 Features

- 📷 Real-time webcam object detection
- 🧠 YOLOv8 AI model (Ultralytics)
- 📊 Object counting on screen
- ⚠️ Alert system for selected objects
- 💾 Saves detection screenshots automatically
- 🌐 Runs in browser using Streamlit WebRTC

---

## 🛠️ Tech Stack

- Python 3.10
- Streamlit
- Ultralytics YOLOv8
- OpenCV (headless)
- PyTorch
- Streamlit-WeRTC
- NumPy & Pillow
